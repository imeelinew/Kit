# 本地测试

在装有项目所需 Xcode 和 macOS SDK 的 Mac 上运行全部自动化测试

```sh
scripts/test.sh
```

入口会运行新增应用测试和现有采集、搜索、去重、保留策略、OCR、预览与撤销回归测试，任一运行器失败时返回非零状态，同时继续运行剩余运行器

只运行指定的新增测试组

```sh
scripts/test.sh classifier geometry paste
scripts/test.sh store settings search
scripts/test.sh palette capture date images
```

重复开发时可以复用仓库之外的构建缓存

```sh
KIT_TEST_BUILD_DIR="$HOME/Library/Developer/Xcode/DerivedData/KitLocalTests" scripts/test.sh
```

未指定缓存目录时，构建和测试产物在临时目录中创建，结束后清理

使用同一个构建缓存目录的测试需串行运行

## 测试范围

| 测试组 | 验证内容 |
| --- | --- |
| classifier | 真实本地分类器，链接、现存路径、代码、Markdown、Unicode 和采样边界 |
| geometry | 调色板定位、吸附和迟滞，贴图尺寸、缩放、屏幕切换与无效输入 |
| paste | 粘贴阶段顺序，每一步失败后的短路，异步取消，通知观察者释放 |
| store | 元数据持久化、分组、文件和图片生命周期、清空、迁移、损坏行、撤销边界和超过内存窗口的历史查询 |
| settings | 缺省和非法值、显式布尔值、旧音效编号、本地化、暂停和保留策略确认 |
| search | 标题和复制元数据，拼音及 Unicode 高亮范围，数据库查询、排序与游标边界 |
| palette | 选择、菜单层级、筛选、分组命名、分页、搜索竞态和撤销后的选择恢复 |
| capture | 敏感标记和应用排除，表示优先级，Unicode 空白和 UTF-8 字节上限 |
| date | 最近 30 天分组、跨年、夏令时、未来时间、本地化和跨日标签刷新 |
| images | 图片指纹、缩略图缓存与失效、OCR 文字到图片区域的映射 |
| 既有回归 | 采集、数据库搜索、去重、保留清理、OCR 重试和回滚、预览渲染与生命周期、键盘撤销 |

新增测试通过 `@testable import Kit` 链接 Debug 应用中的真实实现，不为分类器、渲染器或存储替换桩实现

## 隔离与结果

新增应用测试使用独立测试包标识，数据库和图片放在临时目录，设置测试使用独立偏好设置域

运行器初始化 AppKit 以测试本地视图与渲染逻辑，不启动正式应用的剪贴板轮询、快捷键注册或更新服务，也不写入系统剪贴板

新增测试逐组打印断言数量和失败位置，组内首次失败会停止该组，其余组继续执行，既有回归脚本保留原来的断言和输出方式

新增应用测试默认限时 180 秒，可通过 `KIT_TEST_TIMEOUT` 调整，异步状态检查也设有明确截止时间

统一入口还为每个运行器设置 600 秒的总时限，包含编译时间，超时会结束整个测试进程组并继续其他运行器，可通过 `KIT_TEST_RUNNER_TIMEOUT` 调整

```sh
KIT_TEST_TIMEOUT=300 scripts/test.sh images palette
```

## 仍需人工验证

辅助功能授权、跨进程粘贴、真实剪贴板轮询、登录启动注册、更新下载和安装、菜单栏交互、真实硬件触觉及多显示器拖动仍需人工检查

自动化验证粘贴的事务编排、注入的 OCR 结果和窗口几何逻辑，无法据此保证系统授权、Vision 对所有图片的识别质量或完整界面的视觉表现

现有入口是可直接运行的 Swift 回归套件，不依赖 Xcode 测试目标或 GitHub Actions，断言数量不等同于代码覆盖率百分比
