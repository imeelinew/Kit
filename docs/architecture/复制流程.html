01 · 流程

一次复制，六道关

观察先于分类，闸门先于一切

粘贴板出现 fileURL 或旧版文件名列表时走这里, 不进入文本分类器

02 · 类型

分类器只处理文本

顺序固定：链接 → 路径 → 代码 → Markdown → 文本

文本样本12 个

代码只检查前 12,000 个字符, 并忽略 Markdown 行文中的内联代码示例 · 路径判定需要文件真实存在, 网页演示用开关模拟

链接整段只能是一个带主机的 http(s) URL, 句中链接仍是文本
路径单行绝对路径或 file URL, 目标必须在磁盘上存在
代码JSON、shebang、独立围栏、强语法、独立调用或特征评分 ≥ 3
Markdown只有可见标记才算, 纯段落仍是纯文本

复制文件

粘贴板带 fileURL, 条目保存 fileURLs 与只读安全作用域书签, 交付时写回文件引用

kind file / imageisFileBackedfile_urlsbookmarks

复制路径文本

粘贴板只有字符串, 分类器发现它是存在的路径, 条目只保存 text, 交付时写回文本

kind pathtext无书签在 Finder 中显示

    04 · 状态

    状态改变交付结果

    路径是历史身份, 书签只是访问凭证

    01

    捕获

    先把原始 NSURL 转成只读安全作用域书签, 再保存标准化路径与书签

    02

    预览

    interactive 为 false, 只解析书签与 stat, 失败静默, 不弹授权面板

    03

    交付

    按记录路径重新铸造书签, 不跟随移动到别处的旧书签, 权限不足时才弹面板

    04

    清理

    书签随条目删除、撤销或保留期清理一起消失

    05 · 交付

    三道闸门都通过，才隐藏面板

    权限、载荷、目标按顺序检查, 任一步失败都不会悄悄吞掉操作

    01权限粘贴需要辅助功能, 复制不需要
    02载荷文本、PNG、文件引用或文件租约
    03隐藏载荷准备好后才隐藏面板
    04目标激活并等待最多 800 ms
    05写入与交付写剪贴板并合成 ⌘V
    06历史成功后按设置更新顺序与次数
      单文件不可用 文件不可用：季度报告.pdf

      交互式交付或显示时, 所有 URL 都可交付之前才提示

      整组不可用 文件不可用

      多文件组没有任何成员可读, 准备阶段直接返回

      授权失败 无法访问 季度报告.pdf

      授权面板里选了别的文件, 或授权后仍无读权限

      写入失败 无法复制文件

      writeObjects 没有把文件引用写进剪贴板

      权限缺失 系统辅助功能授权提示

      粘贴前触发, 复制不需要辅助功能

      条件结果说明
      Concealed / Transient / is-sensitive不捕获密码管理器与系统敏感复制
      内部写入标记不捕获Kit 自身写剪贴板时打标
      禁用应用不捕获按来源 bundle ID 排除
      Kit 选择标记可捕获来源改为 Kit, 用于界面内选择复制
      未知来源可捕获没有 bundle ID 时不误杀
      空白文本不捕获Unicode 空白全部排除
      文本超过 8 MB不捕获按 UTF-8 字节计算
      文件与远程 URL 混合整次放弃不退回图像或文本
      非 PNG 图像解码失败回退文本保留原始文本
