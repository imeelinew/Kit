# 文件引用生命周期

文件记录保存原始地址和访问凭据，不保存文件内容副本

## 分类与预览能力

图片类型只用于 Kit 保存独立副本的图像内容，所有外部文件引用统一归入文件，包括单张图片文件与多个文件的组合

图片文件具有单独的图片预览能力，继续支持缩略图、放大预览、图片文字识别与贴图，右侧类型字段显示图片文件，默认复制仍交付文件引用

文件筛选包含图片文件，图片筛选仅包含独立保存的图像内容，分类不由列表采用缩略图还是紧凑行决定

旧版归为图片的文件引用会在数据库迁移时改为文件并保留图片预览能力，迁移不依赖源文件存在，不改变历史标识、复制时间、标题或分组


## 地址语义

| 情况 | 处理 |
| --- | --- |
| 文件仍在原地址 | 使用当前文件 |
| 文件移动或删除 | 保留历史记录，原地址不可用，不通过书签自动追踪新地址 |
| 原地址被新文件替换 | 使用新文件，刷新预览与图片文字索引 |
| 多文件记录部分失效 | 保留完整历史列表，复制当前可访问的成员 |
| 缺少访问权限 | 后台检查不弹窗，显式操作时请求授权，取消后终止本次操作 |
| 临时不可访问 | 保留重试入口，不等同于文件永久删除 |

## 访问与交付

文件检查、书签解析和凭据生成在后台执行，主线程只负责授权窗口、数据库发布和剪贴板交付

一次访问租约持有原始文件对象与安全访问范围，复制、预览、列表缩略图和图片文字识别共用非交互访问实现

复制或粘贴准备完成后，交付前再次检查文件可访问性与元数据签名，目标应用激活期间发生删除、替换或符号链接改向时终止操作，不写入本次内容，也不更新复制次数

下一次操作重新检查文件列表，允许从部分失效的组合中重新准备可用成员

文件引用无法把接收应用之后的读取变成原子事务，交付后文件继续变化仍由文件系统与接收应用处理

## 预览与索引

选中记录的预览定期检查外部文件变化，列表缩略图在加载时重新检查，放大预览同时使用文件版本作为加载标识

活跃预览持有版本缓存条目，避免超过千个文件的组合因缓存淘汰而持续失效，预览缓存的成本包含文件成员数量

图片文字索引持久化文件签名，后台在启动后和周期检查中处理外部图片引用，选中预览也会触发检查

签名包含设备、文件节点、模式、大小、修改时间和状态变更时间，不依赖文件名或进程内缓存编号

源文件变化后只重置派生索引，不修改历史地址、首次复制时间、最近复制时间或复制次数

识别前持有访问租约，识别后再次检查源签名，写回数据库时也要求签名匹配，避免旧结果覆盖已更新的文件状态

删除或权限失败的文件保留有界重试，恢复后签名变化会重新触发识别

## 贴图

贴图先获取访问权限并解码成功，再关闭主窗口

创建的贴图持有解码后的图像快照，原文件之后移动、删除或替换不会破坏已经贴出的图像

## 回归覆盖

自动化覆盖原地址删除与恢复、同路径替换、历史重开、部分可用组合、交付前变化、符号链接改向、取消访问、超过千个文件的预览、索引同步与识别竞态

真实系统授权、网络卷延迟及第三方应用读取剪贴板文件仍需要端到端验证
