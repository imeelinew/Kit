```mermaid
    状态 -->|复制与粘贴操作| 核心
    核心 --> 粘贴[Paster 与 PasteTransaction]
    粘贴 --> 系统剪贴板
    粘贴 --> 目标[原应用或应用内文本框]
    粘贴 -->|成功后更新历史| 历史
    核心 --> 贴图[屏幕贴图 PinnedImageWindowController]
```

## 采集与存储

```mermaid
flowchart LR
    剪贴板[系统剪贴板变更] --> 轮询[每百毫秒检测变化]
    轮询 --> 策略[暂停状态与来源应用检查]
    策略 --> 自写[排除应用自身写入与受限类型]
    自写 --> 快照[后台读取一致性快照]
    快照 --> 流水线[串行采集流水线]
    流水线 --> 文本[文本]
    流水线 --> 图片[图片]
    流水线 --> 文件[文件链接与访问书签]
    文本 --> 规则[本地规则分类]
    规则 --> 仓库[历史仓库]
    图片 --> 仓库
    文件 --> 仓库
    仓库 --> 去重[内容去重与历史顺序维护]
    去重 --> 数据[(条目与分组数据库)]
    去重 --> 图像[(图片文件)]
    仓库 --> 识字[后台图片识字]
    仓库 --> 拼音[后台拼音元数据生成]
    识字 --> 索引[(文字与图片识字全文索引)]
    拼音 --> 索引
    仓库 --> 维护[保留周期清理与图片回收]
    维护 --> 数据
    维护 --> 图像
```

## 检索与操作

```mermaid
flowchart TB
    输入[搜索词与类型及分组筛选] --> 状态[交互状态模型]
    状态 --> 异步[历史仓库异步分页查询]
    异步 --> 引擎[检索引擎]
    引擎 --> 索引[全文索引与拼音及图片识字匹配]
    引擎 --> 补全[索引未完成时补查内存条目]
    索引 --> 结果[按最近复制时间排序的分页结果]
    补全 --> 结果
    结果 --> 状态
    状态 --> 界面[历史列表与内容预览]
    界面 --> 操作[用户选择条目操作]
    操作 --> 变更[分组整理与删除及撤销]
    变更 --> 仓库[历史仓库]
    操作 --> 核心[应用协调器]
    核心 --> 事务[粘贴事务]
    事务 --> 权限[外部目标检查辅助功能权限]
    权限 --> 载荷[准备文字或图片及文件载荷]
    载荷 --> 目标[等待粘贴目标就绪]
    目标 --> 写入[写入带内部标记的系统剪贴板]
    写入 --> 投递[发送粘贴按键或直接粘贴至文本框]
    投递 --> 历史更新[更新历史，连续粘贴延迟发布排序]
    历史更新 --> 仓库
    核心 --> 复制[仅复制至系统剪贴板]
    核心 --> 贴图[创建屏幕置顶图片窗口]
```
